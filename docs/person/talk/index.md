# 记录一下谈话的经验  

1、组饭局最重要的是组局的对象，而不是地点或者其他什么。<br>

2、一个优秀的交谈者，会绘声绘色的讲故事，往往是深情并茂的。<br>

3、良好的谈话，取决于你准备了多少个故事，或者说能想起几个故事。<br>

4、找到共同点，共同点是突破口。<br>

5、话题的切换点，可在一个话题结束时以类似经历引出下一个话题，保持对话连续。<br>

6、特殊称呼需要符合个性。<br>

7、肢体、面部表演。<br>

8、控制自己的表达欲，表现自己的前提是需要倾听，能表现时才尽量表现。<br>

9、不要产生对比、比较的心理，这会加强表现欲，谈话的目的不是听全场夸你。在别人提出一个观点时，哪怕你已经知道，也无需说“我知道”，可以以自己的话讲出来，但无需表达出你此前已知。更无需以另一种方式产生对比，如以另一种方式表现的比其他人更好。<br>

10、注意观察全局人的感受，同时不能过于明显的暴露目的。<br>

11、提建议的方式-不要以居高临下的方式提建议，如刚刚 xx 时，你有 xx 做的不好。改成刚刚 xx 时，如果你 xx，我认为可能会更好。<br>
