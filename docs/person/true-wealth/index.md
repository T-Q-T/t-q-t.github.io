# 如何正确看待财富

曾经有人和我说过，如果突然拥有一大笔财富，那么他会很恐惧。当时不以为意，现在有了一定新的理解，故作此文引以为戒。<br>

常言道-财不外露。其实可以有两个理解思路，对内与对外。<br>

财不外露，大多数人都会觉得当财富过多时，便会引起人们的嫉妒，更有甚者转变为仇恨。这确实是没错的，人的底层逻辑就是如此，会自然仇视那些拥有自己所缺失东西的人。不露财则可从根源上断绝这一切。<br>

而对内，财外露则是会让人产生错误的认知，也就是俗称的飘。财外露，就会有人吹捧你，抬高你，会让人产生源源不断的虚荣心，而虚荣心是永远得不到满足的，就像是拿着一罐蜂蜜，从一开始的舔舐，到后来的大快朵颐。虚荣心会让人产生强大的幻觉，进而一步一步的瓦解自身的意志。为什么很多人会花巨额资金购买名画，消费一些匪夷所思的远超价值的商品就是如此，根源便是虚荣，财外露给他人看，希望因此得到他人的肯定。<br>

大量财富所产生的恐惧便是由此产生。他人的嫉妒会让你遭受道德绑架，无可避免的遭受他人的恶意。自身的虚荣会让你产生无所不能的幻觉，进而守不住财富。就像佛教里的业力一样，人的一切所作所为皆是在积攒所谓的业力，昨日之因终成今日之果，肆意纵火者，终将引火烧身。<br>

很多暴发户守不住财富便是如此，无法正确的正视财富，无法正确的认知自身。避免的方法很简单，也很难，就是始终转化视角看待自己，好好看着存在缺陷而不足的自己，这样既能消除虚荣的幻觉，又可以收敛锋芒，当然并不是说不能享受财富，花钱肯定爽，只是要找到适合自己的度。

提一点题外话，人会因为自己的不足、自身的缺失而产生各种负面情绪进而引发一系列问题。我不经的想，假如一个人完全得到满足，他会是什么样子的，我想，一定是婴儿那样子吧，也难怪古人追求返璞归真之境。每个人诞生起便是完满的人，却随着成长而逐渐缺失这份完满，可笑而无可救药的人。
